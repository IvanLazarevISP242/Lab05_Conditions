## ответы на вопросы

1. int.TryParse() против int.Parse()

- Безопасность: int.TryParse() не выбрасывает исключение (ошибку), если строка не является числом. Он просто возвращает false и записывает 0 в выходную переменную.
- Когда использовать TryParse: При работе с пользовательским вводом, файлами или внешними данными, где формат может быть неверным.
- Когда использовать Parse: Когда вы на 100% уверены в корректности строки (например, она жестко задана в коде) или если неверный формат является критической ошибкой программы.

2. Когда switch удобнее if/else if

- Удобство: switch читается намного легче, когда нужно сравнить одну переменную с множеством конкретных константных значений или шаблонов.
- Пример из жизни: Выбор напитка в кофейном автомате по номеру кнопки (1 — эспрессо, 2 — латте, 3 — капучино, default — «неверный номер»).

3. Что будет, если убрать break в switch

- Результат: Произойдет ошибка компиляции (Control cannot fall through from one case label to another).
- Исключение: В C# запрещено «проваливание» из одного непустого блока case в другой. Убрать break можно только если блок case абсолютно пустой (для группировки нескольких условий) или если вместо него стоит return / throw.

4. Отличие = от == и почему это частая ошибка

- Разница: Одинарное равно (=) — это оператор присваивания (записывает значение в переменную). Двойное равно (==) — это оператор сравнения (проверяет, равны ли два значения).
- Причина ошибок: Новички путают их по привычке из математики, где = означает равенство. В C# компилятор защищает от этого в условиях if (x = 5), выдавая ошибку (так как x = 5 возвращает число, а не bool), но если переменная типа bool (например, if (isReady = true)), код скомпилируется и перезапишет значение вместо проверки.

5. Вложенный тернарный оператор

- Возможность: Да, в C# можно вкладывать один тернарный оператор (?:) в другой.
- Оценка читаемости: Читаемость низкая. Если условий больше двух, код превращается в запутанную строку, которую трудно отлаживать. В таких случаях лучше использовать обычный if/else или switch.
